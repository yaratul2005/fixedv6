# Event Match Quality (EMQ) Guide

EMQ is calculated out of 10 within Facebook Ads Manager. ServerTrack provides a mirrored 0.0 to 1.0 EMQ scoring module to give immediate feedback.

### How to improve EMQ:
1. Always enable the Advanced Matching fields in Settings -> Meta.
2. Enable Contact Form 7 integration to automatically capture lead identifiers.
3. Ensure server-side caching isn't stripping First-Party cookies (`_fbp`, `_fbc`).
